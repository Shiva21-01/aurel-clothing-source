# AURÉL visual assets

Campaign and catalogue concept images were created with the built-in image-generation tool for this project. They depict fictional sample merchandise, not supplier-verified products. Final web assets are in `assets/` as optimized WebP files. The included WebP files are the complete image set used by this downloadable site. The SVG monogram and favicon were drawn directly in code.

The three product contact sheets each contain exactly six columns and three rows. `product.index` maps each product to its corresponding tile using CSS background positioning. Keep the tile order aligned with `data/products.js` when replacing imagery.

Muted palette warm beige, ecru, olive, brown. No jewelry closeups, no handbags, no watermarks. Landscape 1536x1024 or higher.
